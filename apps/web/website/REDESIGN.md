## 二、乔布斯视角的信息补充（第 3 问）

**已实现：**
1. **"Show, don't tell"** — 用真实产品截图开场，标注"真实截图。整个配置流程就是——没有配置流程"。演示即证明。
2. **一个故事，讲透** — 全页只有一个论点：拖延=启动阻力，产品=剪断循环的剪刀。科学版块不是装饰，是论证。
3. **诚实的边界** — 主动写明"不是治疗"。敢说自己不是什么的产品才可信。
4. **创始人在场** — 手记署名"每天早上打开它的那个人"。工具背后有人。
5. **透明定价** — 价格印在官网上，不藏在应用里。
6. **让访客先获得价值再谈转化** — 自测本身就是有用的（不注册、不留数据），CTA 是自然延伸而非拦截。

**建议后续补充（本次未做）：**
7. **15 秒产品视频**（打开→按下计时器→开始写字，一镜到底）——比任何文案都强，素材流水线可产出。
8. **数字诚实**：上线后把"n 个人做过自测/今天有 n 次专注开始"作为活数据展示（真实计数，不造假）。
9. **键盘彩蛋**：官网上按 ⌘K 弹出"你已经会用这个产品了"——把产品体验前置到官网。
10. **桌面版发布时**：平台矩阵区（Web / macOS / Windows）+ 直接下载按钮。

## 二点六、第三轮增强（2026-07-06，用户批准的 1/2/4/5/6 项）

1. **字体自托管**：移除 Google Fonts，复用 app 的 `Fraunces-variable.woff2` + `Manrope-variable.woff2`（preload + @font-face），中文回退系统字体（PingFang SC / Microsoft YaHei）。国内访问不再依赖被墙域名。
2. **15 秒一镜到底 hero 视频**：Playwright 真实录屏（时钟 9:41）：打开仪表盘 → 逐字输入 "Write the launch note" → 回车落板 → 点击 Start Focus → 番茄钟走字。ffmpeg 转 h264，343KB，autoplay/muted/loop，`prefers-reduced-motion` 时暂停并停留海报帧。录制脚本模式可复用于素材流水线。
3. **⌘K 彩蛋**：官网按 ⌘K/Ctrl+K 弹出调色板样式面板——"看，你已经会用这个产品了。→ 打开真正的它"。双语。
4. **Scrollspy**：导航四项随滚动 accent 下划线高亮。
5. **深色模式**：跟随系统 `prefers-color-scheme`，token 映射自 app 深色主题（mint accent #7edbc7）；28 处硬编码墨色 rgba 全部转为 `color-mix(var(--ink-1))` 以便双模式生效；创始人版块固定深绿不随模式漂移。
