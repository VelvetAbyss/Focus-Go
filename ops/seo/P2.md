# P2: language, policy and product identity

Prepared on `codex/seo-p2-trust` from production `ddc431c`.

- English home stays at `/`; Chinese home is `/zh/`. Both include complete initial HTML, language-specific metadata, self canonical and reciprocal en/zh-CN/x-default. Language links follow URLs; browser locale and saved preferences do not change the returned page language.
- Six existing guide routes retain their URLs. Navigation and static policy links preserve the selected language.
- `/privacy/`, `/terms/`, `/zh/privacy/`, `/zh/terms/` render the existing `LEGAL_DOCUMENTS` from `apps/web/src/shared/legal/policies.ts`. Version, paragraphs and consent behavior are not changed. Node 22's explicit type-stripping flag allows the build to reuse this source without duplicating legal text or adding a runtime dependency.
- Published policy paragraphs remain readable without JS. Cloudflare's documented `email_off` boundaries protect the public policy article from email-obfuscation rewrites; the zone setting and access protections are unchanged.
- Twelve sitemap entries are verified against generated routes. The P1 marketing-only Nginx file serving and true 404 rules already support these routes; no app/auth routing migration is needed.
- WebSite, Person and WebPage graphs reflect Focus&go and personal operator Dylan Feng. Homes/guides describe the free Web application; visible breadcrumbs match BreadcrumbList. No company, rating, review count or user count is invented. Without an authentic qualifying review/rating, this does not establish eligibility for Google's software-app rich result.
- Policy/guide stylesheets use the release identifier in the query string to avoid reusing old CDN CSS after publishing.

## Checks

`npm run verify` now includes static language/schema/policy parity checks and four HTTP regression cases: permitted CDN scripts outside unchanged article text; altered policy body; soft 404; Chinese canonical pointing to English. The public verifier reads real Chinese HTML rather than a dormant JS translation dictionary.

After an authorized release:

```
npm run verify:public-site -- --website-url https://nestflow.art/ --app-url https://app.nestflow.art/ --expected-release SHA
npm run verify:discovery -- --base-url https://nestflow.art/
```

Check both homes and policy pages in a browser, including 320/390 mobile widths, and read raw HTML without executing scripts. Validate actual JSON-LD syntax and factual content separately from Google's search enhancement eligibility. No search ranking or AI citation is promised.
