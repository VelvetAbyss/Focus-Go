# Support Focus&go

Focus&go is free for everyone. Optional sponsorship helps fund hosting; it never grants product features or account privileges.

Set the optional public Web variables below to show external links in the in-app Support page:

- `VITE_SUPPORT_GITHUB_URL`
- `VITE_SUPPORT_PAYPAL_URL`
- `VITE_SUPPORT_ZPAY_URL`

Do not add payment secrets, checkout callbacks, or entitlement logic to this project.
