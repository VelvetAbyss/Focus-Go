# 同步状态与本机数据保护

任务、笔记等操作先写入本机，上传在后台进行。页面会显示本机已保存、待上传数量、暂停或离线、上传失败，以及最近一次云端确认。

“云端已确认”要求当前账号完成成功的同步周期，且没有待上传内容、未处理冲突或缺失附件；仅仅打开同步开关或排空队列不算确认。Labs 的独立同步队列也纳入保护，重试同步会处理该队列。

退出、切换账号、注销账号和应用内重置前，会先保存编辑器内容，再检查将被清除的数据。存在未上传内容、冲突、同步错误或缺少当前账号云端确认时，操作暂停，并提供重试和“导出本机备份”。清理事务中还会再次检查，避免漏过刚完成的新编辑。下载提示只代表已发起下载，请确认备份文件已经保存。

应用内重置若已尝试清除云端，但响应中断或本机清理被阻止，会保留本机副本、撤销旧确认，并在恢复同步后重新上传。应用不会凭旧的复制状态把这些记录当作仍在云端。

浏览器自己的“删除站点数据”会直接删除本机数据库，网页无法可靠阻止。清理前请确认云端已确认，或先把备份保存到浏览器之外。本批没有增加独立自动备份或云端历史版本，也无法恢复此前已删除且从未上传的记录。

## 回归验证

大笔记与附件按请求字节数拆批，较大内容分段上传，以兼容 1 MiB 的代理请求限制。中断后保留本机内容和待上传状态；重试复用当前账号已拥有或完整暂存的内容，并续传未完成部分。服务端在同一事务内验证、发布完整内容及记录，不会把半个附件当作已同步。

暂存内容按账号隔离并受空间配额约束，过期一小时后在下次分段上传或内容查询时清理；重置或注销账号也会清理。单条解压后内容的 8 MiB 安全上限仍保留。请求过大与云空间不足分别提示，失败时不自动删除本机内容。
