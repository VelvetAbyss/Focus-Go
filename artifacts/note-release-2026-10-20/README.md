## 使用

- 选中文字显示紧凑单行工具栏，窄屏的下划线、删除线与行内代码收进“更多”。颜色、链接、高亮保留选区；弹层随滚动和缩放跟随锚点并避开视口边界。
- `Alt+F10` 聚焦选区工具栏，方向键切换，`Escape` 返回正文；窄编辑区顶部采用两排布局，格式栏可横向滚动。
- 块菜单支持移动、复制、删除与转换；`Ctrl/⌘+D` 复制当前块或所选块。格式与块操作可逐步撤销、重做。
- 粘贴保留 HTML 格式与表格，电子表格文本可转表格；`Ctrl/⌘+Shift+V` 纯文本粘贴。图片异步插入保持原位置，失败提示可关闭并继续编辑。
- 信息、外观、导入、导出和斜杠菜单统一处理缩放、窄屏及焦点恢复；避免预览服务重写常驻开发服务的依赖缓存。
